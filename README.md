# Dating Chat App

出会い系サイト向けチャットアプリケーション

## プロジェクト概要

50歳以上の男女向け出会い系サイトのチャットシステム

---

## Personality Chat System

16 Personalities性格診断を活用したチャットコメント提案システム

### 特徴
- 性格診断情報のRAG活用
- AIによるコメント提案
- 性格を考慮した応答生成

### セットアップ

仮想環境作成:
    python -m venv venv
    venv\Scripts\activate

パッケージインストール:
    pip install -r requirements.txt

プロジェクト構築:
    python setup_project.py

APIキー確認:
    python test_api_keys.py

詳細は QUICKSTART.md を参照してください。
